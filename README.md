Laboratory Activity: Recursion


Brief Description 
This laboratory activity focuses on recursion and its application in calculating the Greatest Common Divisor (GCD) of two non-negative integers. The program uses the recursive Euclidean algorithm, which repeatedly calculates the remainder until the base case is reached. It also validates user inputs and handles cases where one input is zero.


Programming Language 

Java


Instructions for Compiling and Running 
1. Install the Java Development Kit (JDK). 
2. Open the terminal or command prompt. 
3. Navigate to the folder containing the Java source file. 
4. Compile the program using: `javac -d . gcd/RecursiveGCD.java` 
5. Run the program using: `java gcd.RecursiveGCD`
   


Sample Input

Enter first num: 48

Enter second num: 18


Sample Output
 
 The GCD of 48 and 18 is: 6

Sample Input with One Zero

 Enter first num: 7

Enter second num: 0


Sample Output with One Zero

 The GCD of 7 and 0 is: 7
